# AI塔罗师 — 产品规划与技术方案

> 创建时间：2026-05-27
> 状态：规划阶段，待开发

---

## 一、项目概述

利用无限LLM token优势，开发一个AI塔罗占卜产品。通过H5网页+多渠道分发，以个人开发者身份实现变现。

**核心卖点：** 不是冷冰冰的AI解牌，是有温度的"AI情感陪伴+塔罗指引"。

**目标用户：** 18-35岁女性为主（占80%+），高频问题：感情 > 事业 > 财运 > 健康。

---

## 二、为什么选AI塔罗

| 维度 | AI剧本杀 | AI塔罗 |
|------|---------|--------|
| 合规风险 | ⚠️ 高（凶杀/恐怖/版号） | ✅ 低（归类"心理/娱乐"） |
| 开发成本 | 高（多人房/剧情引擎） | 低（对话框+牌面图片） |
| 用户付费意愿 | 中（要凑人玩） | **极高（焦虑驱动付费）** |
| 复购率 | 中（玩完就走） | **极高（每周都想算）** |
| 获客成本 | 中（需社交裂变） | 低（小红书/朋友圈天然传播） |
| 上架难度 | ⭐⭐⭐⭐ | ⭐⭐ |

```

## 五、渠道策略（不上小程序）

### 5.1 渠道矩阵

| 渠道 | 形式 | 成本 | 作用 |
|------|------|------|------|
| H5网页 | 自助占卜+付费 | 开发1周 | **主变现** |
| 微信私域 | 一对一聊天占卜 | 人工时间 | 高客单价 |
| 公众号 | 自动回复+推文 | 开发3天 | 引流+留存 |
| 小红书 | 自动发内容 | 脚本自动化 | **引流引擎** |
| Telegram Bot | Bot命令占卜 | 开发2天 | 海外增量 |
| Discord Bot | Bot命令占卜 | 开发2天 | 海外增量 |

### 5.2 核心打法

```
小红书（引流）──→ 微信私域（成交）──→ H5网页（自助占卜）
                          ↓
                    公众号（留存）──→ 每日推文（复购）
                          ↓
                  Telegram/Discord（海外增量）
```

只开发一个后端，前端适配多个渠道。

## 六、产品设计

### 6.1 解牌风格（核心差异化）

**不要：**
```
你抽到了"恋人正位"，这张牌代表感情上有新机会，正位表示能量顺畅…
```

**要：**
```
我感受到你最近在感情上有些犹豫。让我帮你看看…
（翻牌动画）
嗯…恋人正位。你知道吗，这张牌出现的时候，往往意味着你心里其实已经有了答案，
只是还没有勇气面对。你愿意告诉我，你在纠结什么吗？
```

**差距：语气、共情、引导用户倾诉。**

### 6.2 人设系统（可选）

用户选择不同解牌师人设：
- **毒舌闺蜜型**：直击要害，不惯着你
- **温柔姐姐型**：温暖治愈，给你力量
- **神秘老者型**：深沉智慧，点到即止
- **理性分析师型**：用心理学框架解读

不同人设用不同system prompt，解同一张牌风格完全不同。

### 6.3 视觉体验

- 精美塔罗牌面图片（AI生图，78张）
- 翻牌动画（CSS 3D transform + 粒子效果）
- 背景音乐/音效（可选）
- 这些边际成本为零但体验感拉满

### 6.4 裂变机制

- "分享到朋友圈可解锁一次免费占卜"
- 塔罗天然有分享欲（"我抽到了死神逆位！"）
- 小红书/朋友圈是天然传播渠道

```

### 7.2 技术栈选型

```
后端：Python FastAPI（快速开发，你最熟）
前端：Vue3 + Vite（H5网页，移动端优先）
数据库：SQLite（起步）→ PostgreSQL（规模化）
支付：微信支付H5支付 / 支付宝当面付
Bot：python-telegram-bot / discord.py
AI：OpenAI-compatible API（通过AiNaiBa网关）
图片：AI生图（gpt-image-2 / Pollinations）
部署：现有服务器（Nginx反代）
```

### 7.3 塔罗牌数据

```
78张塔罗牌 = 22张大阿卡纳 + 56张小阿卡纳

每张牌需要：
  - 牌名（中英文）
  - 正位含义（关键词 + 详细解读）
  - 逆位含义（关键词 + 详细解读）
  - 牌面图片（AI生成）
  - 元素/星座关联

常用牌阵：
  - 单牌占卜（最简单，1张牌）
  - 三牌阵（过去/现在/未来）
  - 凯尔特十字（经典10牌阵）
  - 爱情十字（感情专用）
  - 事业金字塔（工作专用）
```

### 7.4 解牌Prompt设计（核心）

```python
SYSTEM_PROMPT = """
你是一位塔罗牌解读师「{persona_name}」。

## 你的风格
{persona_description}

## 规则
1. 用温暖、有同理心的语气与用户对话
2. 先倾听用户的困惑，再解读牌面
3. 解读时结合用户的实际问题，不要泛泛而谈
4. 不要预测具体的未来事件，而是提供思考方向
5. 每次解读控制在150-300字
6. 结尾用一个引导性问题，鼓励用户继续对话
7. 不要说"作为AI"，保持角色人设

## 你抽到的牌
牌名：{card_name}
位置：{position}（如"过去"、"现在"、"未来"）
正逆位：{orientation}

## 牌义参考
{card_meaning}

## 用户的问题
{user_question}

请用你的风格解读这张牌。
"""
```

### 7.5 内容安全

```
必须做的：
1. 输出过内容安全API（阿里云/腾讯云内容审核）
2. 不承诺准确率，不说"预测未来"
3. 所有页面加免责声明："仅供娱乐参考，不构成任何建议"
4. 敏感话题过滤（自杀/自残/严重心理问题 → 引导专业求助）
5. 每日占卜次数上限（免费用户3次/天）

话术包装：
  不说"算命" → 说"心灵指引"/"自我探索"
  不说"预测" → 说"看看牌面给你的启示"
  不说"大师" → 说"解牌师"/"指引者"
```

## 十、合规要点（运营中持续注意）

```
1. 产品名：心灵指引/自我探索/每日运势（不叫"AI算命"）
2. 免责声明：所有页面标注"仅供娱乐参考，不构成任何建议"
3. 不说"预测"、"算命"、"大师"、"100%准确"
4. 内容安全：输出过审核API，敏感话题过滤
5. 未成年人：设消费限额或禁止付费
6. 退款机制：不满意秒退，减少举报
7. 域名备案：H5网页需要ICP备案
8. 个人收款：微信支付H5支付或支付宝当面付
```
