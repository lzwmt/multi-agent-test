## 项目概述

用 AI 辅助生产，每天生成 15-20 分钟的播客节目。**核心定位：一个程序员用 AI 工具研究投资的实操记录。**

目标 12 个月内达到 5000+ 订阅，通过 Newsletter + 社群实现被动收入。

## 定位（v2：深度单话题模式）

- **节目名**: 「代码与财富」
- **口号**: "用代码理解世界，用AI管好钱包"
- **赛道**: AI × 投资（程序员如何用 AI 研究投资）
- **时长**: 15-20 分钟/期
- **频率**: 工作日更（周一到周五）
- **风格**: 个人观点 + 实操分享，不是念新闻
- **语言**: 中文为主，偶尔英文术语
- **差异化**: 不是泛财经播客，是"教你用 AI 这个工具去研究投资"

### 人设

**身份**: 一个用 AI 研究投资的程序员
**关键词**: 真实（分享操作包括失败）、务实（不吹牛只说可验证的）、技术派（用数据和工具说话）、学习者（和听众一起学）

### 内容比例

| 类型 | 比例 | 说明 |
|------|------|------|
| AI×投资交叉 | 60% | 核心差异化，蓝海市场 |
| AI/技术 | 25% | 程序员本行，建立专业度 |
| 投资/理财 | 15% | 纯投资内容少做，避免同质化 |

### 内容矩阵

#### 一级主题：AI投资工具箱

| 系列 | 内容 | 示例选题 |
|------|------|----------|
| **AI读财报** | 用AI自动分析上市公司财报 | "我让GPT读了英伟达10-K，发现了什么" |
| **AI选基金** | 用AI筛选和对比基金 | "Claude帮我筛出了5只低费率纳斯达克ETF" |
| **AI看研报** | 用AI提取券商研报核心观点 | "AI对比了5家券商对特斯拉的评级，结论..." |
| **AI做量化** | 用AI写量化策略并回测 | "ChatGPT写了一个均线策略，回测结果..." |
| **AI监控** | 用AI监控市场信号 | "我用AI做了一个北向资金监控机器人" |

#### 二级主题：AI投资实验

| 系列 | 内容 | 示例选题 |
|------|------|----------|
| **AI vs 人类** | AI选股 vs 专家选股对比 | "AI选的基金 vs 财经大V选的，3个月后谁赢了" |
| **AI实盘记录** | 用AI辅助的真实投资记录 | "AI建议我买XX，我买了，现在..." |
| **工具横评** | 不同AI工具的投资分析能力对比 | "GPT-5 vs Claude vs Gemini，谁更适合分析股票" |
| **失败复盘** | AI分析失败的案例 | "AI说会涨，结果跌了，我学到了什么" |

#### 三级主题：程序员投资思维

| 系列 | 内容 | 示例选题 |
|------|------|----------|
| **代码思维投资** | 用编程思维理解投资 | "Debug思维：如何排查投资逻辑的bug" |
| **自动化投资** | 程序员的自动化投资系统 | "我用Python做了一个自动定投系统" |
| **数据驱动** | 用数据分析代替主观判断 | "我统计了10年数据，发现定投的最佳频率是..." |

## 生产管线设计（v2：AI分析+审核模式）

```
┌─────────────────────────────────────────────────┐
│                 每日自动管线                       │
├─────────────────────────────────────────────────┤
│                                                   │
│  06:00  选题抓取（AI自动）                         │
│    ↓    news-aggregator + RSS（10源）              │
│    ↓    AI/投资关键词打分排序                       │
│                                                   │
│  06:15  AI投资分析（AI自动）                       │
│    ↓    用GPT分析今日最佳选题                      │
│    ↓    生成分析结论 + 投资洞察                    │
│                                                   │
│  06:30  脚本生成（AI自动）                         │
│    ↓    15-20分钟深度单话题脚本                    │
│    ↓    包含：背景、分析过程、观点、建议           │
│                                                   │
│  07:00  ⚠️ 人工审核（你来，10-15分钟）             │
│    ↓    看一眼选题是否合适                         │
│    ↓    看一眼脚本是否合理                         │
│    ↓    加上你的个人观点/经历                      │
│    ↓    确认发布                                  │
│                                                   │
│  07:15  TTS生成（AI自动）                         │
│    ↓    MiMo TTS → 原始音频                       │
│                                                   │
│  07:30  音频后处理（AI自动）                       │
│    ↓    片头BGM + 片尾BGM + 音量标准化            │
│    ↓    ID3 tags + 封面图嵌入                      │
│                                                   │
│  07:45  发布（AI自动）                             │
│    ↓    更新RSS feed.xml                          │
│    ↓    推送到GitHub Pages                        │
│                                                   │
└─────────────────────────────────────────────────┘
```

**你的工作量：每天10-15分钟审核+个性化**

## 风险点

- **TTS 质量**: MiMo 已经不错但长文本仍可能机械感 → 后期考虑 ElevenLabs
- **内容同质化**: 需要有独特观点，不能纯 AI 搬运
- **增长慢**: 播客是慢生意，3-6 个月才有明显起色
- **平台审核**: 部分平台可能限制 AI 生成内容 → 需要了解各平台政策
- **投资风险**: 涉及投资内容需谨慎，避免荐股嫌疑
