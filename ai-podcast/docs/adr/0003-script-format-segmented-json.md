# ADR-0003: 脚本格式采用分段 JSON

## 状态
已采纳

## 背景
脚本输出直接喂给 TTS。需要决定是纯文本还是分段结构化格式。

## 决定
采用分段 JSON 格式，每段包含：
- `type`: section 类型 (intro/topic/tool_rec/outro)
- `text`: 口播文本
- `pause_after_ms`: 段间停顿（毫秒）
- `bgm`: BGM 标记（可选）

## 理由
- 分段 TTS 可以单独重生成某段，不用整期重来
- 可精确控制节奏（段间停顿）
- 可在段间插入 BGM
- 多写 20 分钟代码，换来音频处理的完全灵活性

## 替代方案
- 纯文本模式：简单但无法分段控制，否决
