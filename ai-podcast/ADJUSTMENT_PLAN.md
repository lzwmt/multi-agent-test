## 四、新脚本模板

### 开场（1分钟 / 200字）
```
大家好，欢迎收听「代码与财富」。我是XX，一个每天用AI写代码也用AI研究投资的程序员。

今天的口号是：用代码理解世界，用AI管好钱包。

今天我想聊一个最近让我挺纠结的事——[一句话引出话题]。
```

### 今日主角（10分钟 / 2000字）
```
[话题背景]
最近[事件/新闻]，我第一时间用[AI工具]做了一番分析...

[我的分析过程]
我让[GPT/Claude]帮我[具体操作]，发现...

[我的观点]
说实话，我觉得[个人观点，要有依据]...

[可执行建议]
如果你也是程序员，想[行动建议]...
```

### AI工具实测（5分钟 / 1000字）
```
最后给大家推荐一个我最近在用的[工具名称]。

[工具简介]
这是一个[功能描述]...

[我的使用体验]
我用它来[具体场景]，发现[真实体验]...

[优缺点]
优点是[...]，缺点是[...]...

[适用场景]
如果你[场景描述]，可以试试。
```

### 一句话建议（1分钟 / 100字）
```
好了，今天的节目就到这里。

今天的一句话建议是：[今日投资感悟]。

如果你觉得有收获，欢迎订阅分享。我们下期再见，拜拜！
```

## 五、人设规范

### 核心人设
> "一个用AI研究投资的程序员"

### 关键词
- **真实** — 分享自己的投资操作，包括失败
- **务实** — 不吹牛，只说可验证的
- **技术派** — 用数据和工具说话
- **学习者** — 不是专家，是和听众一起学习

### 可以说
- "我最近在研究XX"
- "我用XX工具分析了XX，结论是..."
- "这个我也不太确定，但我的判断是..."
- "这只是我的个人操作，不构成投资建议"

### 不能说
- "你应该买XX"
- "这个肯定会涨"
- "跟着我操作稳赚"

### 必须有
- 涉及投资操作时加免责声明
- 展示分析过程，不是只给结论
- 承认不确定性
